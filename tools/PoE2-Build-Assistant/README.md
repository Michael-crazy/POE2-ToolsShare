# PoE2 配装助手（PoE2-Build-Assistant）

中文 PoB + 游戏内装备评估助手，支持流放之路2 国际服和国服（腾讯）。

**项目主页：<https://github.com/Michael-crazy/PoE2-Build-Assistant>**（代码、说明、问题反馈都在那里）

## 能做什么

- **游戏内装备评估**：游戏里指向装备按快捷键，浮层显示这件装备对你 PoB 当前 BD 的提升（DPS、有效生命、抗性、属性缺口），市集里还会算性价比。
- **PoB 全汉化**：界面、技能、天赋、装备、词缀、宝石提示都是简体中文，术语用流放编年史的译名。
- **查价**：国服、国际服都能在工具里查价；PoB 自带的市集交易支持国服，能按 BD 缺口找装备、按性价比排序。
- **自带市集窗口**：在助手里打开官方市集，每条结果旁显示试算。
- **导入国服角色**：贴 WeGame 分享链接导入装备、天赋、珠宝和技能。
- **AI 问 BD（MCP）**：在 Claude 等 AI 客户端里用中文查技能、出 BD、问“我当前 BD 的 DPS”。
