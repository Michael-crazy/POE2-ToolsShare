# BD 装备高亮

## 从 BD 提取匹配条件

接受用户的装备清单、PoB 导出或已提供的 BD 内容。确认目标过滤器、BD 阶段和角色实际需要的装备槽位。把推荐装备拆成必需暗金、可用底材或类别、可辨识的属性要求。按需记录稀有度、物等、护甲或能量护盾等基础防御、孔数、品质、腐化状态和已鉴定词缀。区分当前装备、可掉落底材与最终制作成品。用户只要求关注某类时，按类别处理。能确定具体底材时，优先用客户端认可的精确 BaseType。

共享暗金底材需要同时限制 Unique 稀有度。不能区分具体暗金时，只有用户接受底材候选提示才高亮，并在摘要说明。未鉴定掉落按可识别的底材和属性匹配，无法判断的词缀或成品组合列为待确认。

## 保住现有命中和表现

- 以用户选中的过滤器版本为基础，包含它现有的市集规则。BD 只增加视觉提示，保留原显示状态、声音、光柱、地图图标及已有价格提示。默认只对有空余的边框样式加 BD 标记。若原规则已占用该视觉属性，可选另一项未用且能保持原视觉含义的属性。无法同时表达时标注冲突，由用户决定能否覆盖一项视觉属性。
- 对无 Continue 的脚本，在实际命中的原 Show 块之前插入其副本，将条件收窄为原条件与 BD 条件的交集，只增加选定的视觉动作。保留原 Show，各档的 Hide 不动。只有能证明交集成立时才生成规则。精确列表可用交集，部分匹配需要用已核实的底材或类别证明收窄有效。对于同一字段，优先收窄已有条件、取交集或拆成互斥块，并核对客户端行为。
- 一个 BD 目标可能分散在多条 Show 中，各自继承实际命中块的音效和样式。保留 CustomAlertSound、CustomAlertSoundOptional、PlayAlertSound、PlayAlertSoundPositional 以及掉落音效开关和音量。保持其他物品和后续兜底的命中顺序。默认保留严格档的隐藏行为。用户明确要求额外显示时，再另行处理范围和样式。
- 若有 Continue、Import 或已有视觉覆盖，先追踪完整匹配链。只有能证明候选保持原有可见性、声音与非 BD 掉落行为，且最终视觉提示实际生效，才应用改动。不能确定的规则列为待核实。重新市集调档后，复用最新命中块重新生成 BD 高亮，避免旧高亮继续继承过期样式或声音。

## 交付验证

记录 BD 匹配条件、目标档位、所加视觉动作和未能映射的需求。至少核对可见 BD 装备、同类非 BD 装备、同一底材的其他稀有度、被前置 Hide 命中的目标及不同市集音效的命中。按 editing.md 检查静态结构和音效路径。目标客户端可用时加载复核，并报告实际验证范围。
