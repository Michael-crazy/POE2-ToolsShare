# 七档用途与等级范围

以下策略来自文子七档实际 Show/Hide、等级条件和末尾兜底。应用时重新读取待更新文件，各版本可能已有改动。

| 档位 | 用途与原档策略 |
| --- | --- |
| 1 开荒（1–70） | 优先角色成长和换装。保留开荒装备、低级通货、药剂、护符及宝石。普通黄装保留全局显示，蓝白装按前置例外显示。 |
| 2 异界（50–80） | 初入异界仍需要地图、补给和升级底材。开始隐藏普通黄装兜底、部分低价通货和蓝白装，保留特定装备和词缀。 |
| 3 过渡（80+） | 收紧通货、地图和低阶宝石，集中显示适合下一阶段的底材与装备。沿用实际物等和底材名单。 |
| 4 进阶（81 物等） | 保留当前需要的 81 物等底材和高价值匹配，进一步收紧地图、材料和低阶掉落。个别 81+、82+ 或更高物等规则按正文保留。 |
| 5 速刷（82+ 物等） | 减少低价通货和耗时拾取，保留重点 82+ 底材、地图供给与高价值例外，谨慎增加频繁音效。 |
| 6 打宝（82+ 物等） | 以高价值掉落与热门 82+ 底材为主，减少普通装备、宝石和地图提示。原版有 86+ 等前置例外，保留具体条件。 |
| 7 进阶打宝 | 拾取最精简，进一步收紧材料、暗金和装备。实际仍有部分 82+ 底材与 88+ 装备例外，按正文处理。 |

## 更新时怎么用

1. 分清文件名描述的使用阶段、角色等级、区域等级、物品等级、底材掉落等级、地图阶级和宝石等级。条件里的 ItemLevel、AreaLevel、DropLevel、WaystoneTier、GemLevel 各用于相应维度，按目标版本支持及原规则核对。第 1 至 3 档的范围是档位使用说明，原文件含不同物等规则。第 4 至 6 档的物等提示用于选择装备策略。不要从文件名推导适用于所有掉落的全局等级条件。
2. 针对实际细分条目，保留所选档的物等、地图阶级、宝石等级、稀有度及其比较符。特别核对等于和大于等于的区别。同一新掉落按同类旧规则决定每档显示和样式。开荒侧重供给，打宝侧重价值和拾取成本。没有可比规则的新掉落，保留原兜底行为或按用户确认的策略处理。
3. 市集按同底材、同物等段、同稀有度与可辨别属性估价。价格可以调整该档的样式和音效，改动 Show/Hide 仍按用户授权。BD 高亮继承该档的首条实际命中条件。不要把某档对同名物品的显示或音效批量复制到其他档。
4. 不假设档与档之间的 Show 集合严格包含。例：原第 3 档与第 4、5 档在 19 级技能宝石的规则覆盖上不同。逐档验证先命中规则，选改动阈值的下方、等于和上方样本，再检查同类对照、地图补给和全局兜底。摘要记录所处理档位与各档保留的等级条件。
