# 游戏目录部署

## 定位和预览

1. 以游戏过滤器设置里的「打开文件夹」定位实际使用的目录。用户也可以提供目标区服的目录。多个目录或档位不明确时确认目标。只处理本地普通 .filter 文件。账号订阅、同步缓存和音效目录不属于原位覆盖范围。
2. 运行时把候选工作区和目标游戏目录选为两个根。从各自根解析相对文件名。配置、变更清单和迁移包只保存相对路径与根目录角色。机器上的实际路径可用于当次定位、权限申请和确认，避免写入可迁移文件。
3. 只读检查目标并记录原文件 SHA-256，在工作区准备候选并记录候选 SHA-256。按任务执行手动调整、赛季升级、市集分档或 BD 高亮。在目标目录布局下核对 Import 和音效。候选与目标的依赖布局不同，先验证同目录关系或在工作区镜像中复现目标布局。候选重放既有规则时保留原档位、声音和相对路径。
4. 向用户展示候选、拟覆盖的文件清单、具体目录、变更摘要、验证情况和备份安排。明确取得对该候选和目标的同意后，才允许写入游戏目录。候选或目标内容在同意后发生变化时重新预览。系统若限制写入该目录，按实际目标申请工具权限。

## 覆盖和回滚

1. 使用当前环境可用的文件操作。覆盖前重新核对候选和目标哈希，以及解析后的目标是否仍是用户确认的游戏目录内的同一普通文件。多档覆盖先核对整份获准清单。
2. 逐档在目标旁创建唯一的 .bak 备份并核对备份字节。将候选写入目标目录的临时文件，核对候选哈希，再用当前平台支持的同目录原子替换操作覆盖目标。读回核对哈希。发生错误时停止后续覆盖，报告已完成项与备份位置。
3. 需要回滚时先确认要恢复的版本，再用对应备份走同样的替换与读回校验。覆盖后在游戏内重新加载过滤器，并记录实际验证结果。
