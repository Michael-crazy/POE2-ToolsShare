# 下载基础过滤器

用户本地没有可用的 PoE2 过滤器时，可从 [基础过滤器-文子过滤器](https://github.com/Michael-crazy/POE2-ToolsShare/tree/main/shareAsset/%E5%9F%BA%E7%A1%80%E8%BF%87%E6%BB%A4%E5%99%A8-%E6%96%87%E5%AD%90%E8%BF%87%E6%BB%A4%E5%99%A8) 获取七档和原配音效。若 Skill 与资源同在仓库，先检查仓库根目录下的相对路径 shareAsset/基础过滤器-文子过滤器。也可下载 [仓库 ZIP](https://github.com/Michael-crazy/POE2-ToolsShare/archive/refs/heads/main.zip)，只从其中提取该目录到工作区，保留文件名及子目录。

这是历史赛季底版。先按使用场景选择档位并核对与目标区服、赛季的兼容性，需要时按 season.md 升级。检查 .filter 中的相对音效路径。底版的文子过滤音效位于内层「过滤及音效」目录，准备可加载的候选副本时，将该音效目录置于候选 .filter 文件同级，或在校验时用包含它的内层目录作为音效根。安装到游戏目录前按 game-deploy.md 确认目标与文件清单。
